# AdScriptValidator brand blocklist (SPEC F160.3, STORY-390 AC4) — real-world brand names an ad
# script must never name. Data, not config: this file grows by PR, no code change required.
#
# Format: one phrase per line, `#`-prefixed and blank lines are comments. Every phrase is folded
# (AdCopyFold.Fold — case, leet-speak, separator-punctuation collapsed to single-space tokens) at load
# and matched word-boundary against the SAME folding of the script text (FoldedWordListMatcher).
#
# PRECISION BIAS (deliberate, documented): entries favor multi-word/distinctive forms ("coca cola",
# "mcdonald's") over bare single-word brand names. A bare single word that ALSO reads as ordinary
# English (apple, target, visa, amazon, marvel, crest, jeep, barbie, intel, snickers) is the noisy
# false-positive class — those are either qualified into a multi-word phrase here ("target corp",
# "visa card", "amazon.com", "marvel studios", "crest toothpaste", "jeep wrangler", "barbie doll",
# "intel corp", "snickers bar") or left off the list entirely (bare "apple" is intentionally absent —
# "iphone"/"macbook"/"apple inc" cover the brand without colliding with the fruit; see the pinned
# negative fact for "applesauce"). Single-word entries that DO stay bare are names with no ordinary
# dictionary sense (nike, toyota, spotify, ...) — a cheap, honest precision/recall tradeoff, not a
# claim of completeness.
